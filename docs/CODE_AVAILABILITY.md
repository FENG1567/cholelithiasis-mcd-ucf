# Code availability

## Current repository status

The reproducibility package is maintained in the private GitHub repository
[`FENG1567/cholelithiasis-mcd-ucf`](https://github.com/FENG1567/cholelithiasis-mcd-ucf). It is not publicly accessible at present. This repository has no public release, DOI, or selected software licence. `LICENSE_PENDING.txt` remains a rights-and-licence placeholder and is not a licence grant.

The repository contains the code used for aggregate analyses, publication-figure recreation, and release-integrity checks, together with aggregate tables, figure source data, and archived CDC WONDER query specifications. Individual death-certificate records, restricted source files, credentials, personal paths, and record-level audit examples are not included.

Before public release, the authors must confirm author and institutional rights, select an appropriate software licence, and create a versioned public release. The repository and archive identifiers in `CITATION.cff` and the manuscript data-availability statement should then be updated. No DOI or public archive identifier is assigned at present.
