# Code availability

## Current repository status

The reproducibility package is publicly available in the GitHub repository
[`FENG1567/cholelithiasis-mcd-ucf`](https://github.com/FENG1567/cholelithiasis-mcd-ucf). The current versioned release is
[`v0.1.0`](https://github.com/FENG1567/cholelithiasis-mcd-ucf/releases/tag/v0.1.0),
released under the MIT License. No DOI or public-archive identifier has been
assigned.

The repository contains the code used for aggregate analyses, publication-figure recreation, and release-integrity checks, together with aggregate tables, figure source data, and archived CDC WONDER query specifications. Individual death-certificate records, restricted source files, credentials, personal paths, and record-level audit examples are not included.

The release includes the repository metadata in `CITATION.cff` and the MIT
license in [`LICENSE`](../LICENSE). It does not include individual
death-certificate records or other restricted source data.
